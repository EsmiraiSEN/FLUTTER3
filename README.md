## Запуск
1. Клонировать репозиторий: `git clone <ссылка_на_ваш_репозиторий>`
2. Перейти в папку проекта: `cd first_flutter_app`
3. Выполнить команду: `flutter pub get`
4. Запустить проект в браузере: `flutter run -d chrome`
